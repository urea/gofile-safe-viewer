v0.12.0：URLのブックマーク機能を追加しました。

・閲覧画面の「☆保存」から、現在表示しているURLをブックマークできます。
・保存済みURLでは「★保存済」と表示し、もう一度押すとブックマークから削除できます。
・ホームの「ブックマーク」から保存URLを一覧表示し、タップして再度開けます。
・一覧から不要なブックマークを削除できます。
・ブックマークは端末内に保存し、「ログイン・閲覧データを削除」では削除しません。

閲覧先の許可条件、Cookie・WebStorageの扱い、更新APKの検証条件、固定署名鍵は変更していません。v0.10.0以降の配布版から通常の上書き更新が可能です。
