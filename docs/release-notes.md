ホーム画面を追加しました。
・アプリの説明、許可リスト概要、情報の扱いを表示します。
・Xを開く／Xにログインするボタンを追加しました。
・ログイン状態は端末内で保持し、ホームから明示的に削除できます。
・GitHub Releasesからの手動更新確認と、確認付きAPK更新に対応しました。
・サイズ、SHA-256、アプリ識別子、バージョン、署名を検証してからAndroidの更新画面を開きます。

v0.9以前はdebug署名のため、この配布版への初回切り替えだけ入れ直しが必要になる場合があります。アンインストールすると以前のログイン状態等は削除されます。以後は固定署名鍵で上書き更新します。
