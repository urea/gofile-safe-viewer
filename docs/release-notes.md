v0.11.0：画面上部の視認性と操作を改善しました。

・ホームと閲覧画面のステータスバーを白背景・濃色アイコンに統一しました。
・時計、通知、電池、画面の切り欠き、ナビゲーション領域に内容が重ならないよう調整しました。
・動画の全画面表示から戻った後も、通常のシステムバー配色と余白を復元します。
・閲覧ヘッダーのタイトル、ホームボタン、URL欄、開くボタンのサイズと配置を整理しました。ボタンのタップ範囲は48dpを確保しています。
・通常時の「表示中：URL」の重複表示をやめ、読み込み中や遮断・エラー時だけ案内を表示します。
・「Xにログイン」を削除し、「Xを開く」に一本化しました。必要なログインはXの画面内で行えます。

許可条件、ログイン状態の保持、更新APKの検証条件、署名鍵は変更していません。v0.10.0からはホームの「更新を確認」から上書き更新してください。
